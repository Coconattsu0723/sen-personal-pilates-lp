## 使用ルール

- 正式素材の画像内容、色、明るさ、サイズ、トリミング、圧縮、画質、透過状態を元ファイル側で変更しない
- 実装上の表示サイズや表示領域はCSSで制御する
- パスはこの台帳の相対パスを使用する
- 同用途の別画像を勝手に追加しない
- 画像内へ文字・ロゴ・装飾を追加しない
- 代替テキストは用途と文脈に合わせて実装時に決める

## 一般UIアイコン

以下は正式画像素材として追加せず、必要に応じてインラインSVGまたはCSSで実装する。

- Menu
- Close
- Arrow
- FAQ ＋ / −
- Check
- Calendar

外部アイコンライブラリの採用は未確定。使用する場合は実装前に要確認。

## CHECK / PLAN / MOVE

専用の新規画像は必須としない。文字主体、既存アイコンとの共用、または簡潔なSVG / CSS表現を候補とし、実装時に決定する。

## 公開前に要確認

- Web表示向け軽量化：2026年8月24日完了。原本と派生ファイルを併存して管理する
- `srcset`：現時点では不採用。単一派生ファイルで最大表示寸法の約2倍を確保する
- OGP画像：1200×630pxのWeb表示用派生版を作成済み。公開URL確定後にHTMLへ設定する
- favicon：48×48pxのWeb表示用派生版を作成しHTMLへ設定済み
- 各画像の`alt`：Accessibility工程で確定済み。参照先変更後も文言を維持する
