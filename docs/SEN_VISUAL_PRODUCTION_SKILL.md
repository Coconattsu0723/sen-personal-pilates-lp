# SEN PERSONAL PILATES｜Brand & Visual Production Skill

## 1. このSkillの目的

このSkillは、ポートフォリオ用の架空LP **「SEN PERSONAL PILATES」** で使用するロゴ・写真・イラスト・アイコン・図解などの正式素材を、別チャットでも一貫したブランド方針で制作するための正本ルールです。

画像制作時は、このSkillに記載されている内容を優先してください。

既に確定しているブランド設定・コピー・配色・人物設定・サービス内容を、画像制作の都合で勝手に変更しないでください。

この制作は「見た目がおしゃれなピラティスLP」を作ることが目的ではありません。

ターゲットの課題から、

**自分の身体を知る → 自分に合った方法で整える → 無理なく続ける**

という体験を設計することが目的です。

かわいく丸めすぎない。

基本は、

で階層を表現する。

### レイアウト

カードを大量に並べない。

## 18. 写真の共通ルール

### 光

- 柔らかい自然光
- 日中
- 強い逆光NG
- 強い影NG
- 白飛びNG

### 色

- 低〜中彩度
- 暖色に振りすぎない
- Warm Ivory / Sage / Charcoalと調和させる

### 人物

- 過剰な笑顔NG
- 広告モデルのポーズNG
- カメラ目線を多用しない
- 会話中・集中中など自然な瞬間
- 過度な美肌加工NG

### 身体表現

- 腹筋強調NG
- ヒップ強調NG
- 痩身訴求NG
- 体型を商品化する表現NG

「美しい身体」ではなく、**身体と向き合っている時間**を表現する。

### AI画像感を抑える

- 過度に完璧な人物
- 不自然に整った室内
- 過剰な被写界深度
- 不自然な肌
- 過剰な広告照明

を避ける。

## 23. 姿勢チェック図解

正式採用済み。

写真ではなく、SEN独自の説明図として使用する。

候補：

- 正面
- 横向き
- 身体の軸線

ラベル例：

- HEAD
- SHOULDER
- PELVIS
- BALANCE

目的：医学的な診断を表現することではない。

**「SENではこのような観点から身体を確認します」**と分かりやすく説明するための図解。

医療図解のような表現にはしない。

## 31. 画像生成時の重要ルール

複数素材を依頼された場合でも、ユーザーから特別な指示がない限り、**1画像につき1素材**を基本とする。

特にアイコン制作では、

- コラージュにしない
- 一覧画像にしない
- 比較シートにしない
- 1枚に複数アイコンをまとめない

正式素材として使用しやすい状態で出力する。

透過指定がある場合は、背景を完全透過にする。

画像内に不要な文字・ロゴを勝手に追加しない。

---

## 32. このSkill使用時のAIへの指示

SENの正式素材を制作するときは、必ずこのSkillを基準に判断すること。

ユーザーから素材制作依頼を受けた場合、

1. その素材がLP内で何の役割を持つか確認
2. SENのブランド人格との整合性を確認
3. 既存素材とのシリーズ感を守る
4. 過度な装飾を追加しない
5. 写真を不要な場所へ増やさない
6. 人物を不要に追加しない
7. 確定済み設定を変更しない

こと。

見栄えを良くするためという理由だけで、ブランド方針を変更してはいけない。
