# SEN PERSONAL PILATES｜Design Rules

## この文書の役割

LPの見た目、UI、写真、余白、レスポンシブ表現を定義するデザイン正本。

## ビジュアルコンセプト

- 正式採用：**Natural Calm**
- コンセプト：**身体と向き合う、静かな余白。**

### デザインキーワード

- 余白
- 自然光
- 静けさ
- 清潔
- 身体
- 軽やかさ
- 丁寧
- ミニマル

ナチュラルではあるが、かわいすぎる方向、韓国系淡色ブランドへの過度な寄せ、オーガニックコスメやカフェのような表現にはしない。

## 正式カラー

| 用途 | 名称 | HEX | 使用方針 |
|---|---|---|---|
| Main Background | Warm Ivory | `#F7F5F0` | ページの主要背景 |
| White Background | Soft White | `#FCFBF8` | 背景の切り替え、カード等 |
| Main Text | Deep Charcoal | `#303431` | 見出し、本文の主要文字 |
| Secondary Text | Warm Gray | `#747873` | 補足、メタ情報 |
| Brand Color | Sage Green | `#89988B` | 小見出し、数字、細線、小さなアクセント |
| Pale Background | Pale Sage | `#E6EAE4` | 控えめな背景差 |
| CTA | Deep Sage | `#66776A` | 主要CTA |
| Border / Line | Light Gray | `#DADDD7` | 境界線、区切り |

### カラー使用ルール

- Warm Ivory / Soft Whiteを広く使う
- Deep Charcoalで情報を整理する
- Sageは少量に限定する
- セージグリーンを背景全面や多数のカードへ大量使用しない
- 色だけで状態や意味を伝えない
- 文字と背景のコントラストは実装時に確認する

## フォント

### 日本語

- **Noto Sans JP**
- 本文：400
- 見出し：500〜600程度
- Boldを多用しない

### 英字・ブランド表現

- **Cormorant Garamond系の細身セリフ**
- SEN / PERSONAL PILATES / ABOUT / LESSON / TRAINER / PRICEなど短い英字に使用

### 原則

```text
英字＝セリフ
日本語＝サンセリフ
```

Webフォントの読み込み方法、フォールバック、実際のウェイトは実装前に要確認。

## 文字設計

SP 375px時点の方向性：

| 要素 | 目安 |
|---|---:|
| Hero `h1` | 32〜38px |
| セクション `h2` | 28〜32px |
| 本文 | 15〜16px |

固定値として確定せず、改行、可読性、実機表示を確認して実装レビューで調整する。Heroだけに`h1`を使用し、主要セクションは`h2`とする。

## 余白

### セクション間余白の目安

| 画面 | 目安 |
|---|---:|
| SP | 80〜96px |
| PC | 120〜160px |

- 固定値としては未確定
- コンテンツ密度と前後関係を見て実装レビューで最終調整する
- 1画面に情報を詰め込まない
- 余白もブランド表現の一部として扱う

## 角丸

| 要素 | 目安 |
|---|---:|
| CTA | 10〜14px |
| Card | 8〜12px |
| Photo | 0〜16px |

- 丸すぎるUIにしない
- ピル型を多用しない
- 要素ごとの役割に応じて統一する

## Shadowと境界

強い`box-shadow`は禁止する。階層は主に以下で表現する。

- 背景色の差
- 1px Border
- 余白

影が必要な場合も、ごく弱く限定的に使用する。

## レイアウト

### SP（〜767px）

- 375pxを正本とする
- 素直な縦構成
- コピー → CTA → 写真のように自然に流す
- 1画面に情報を詰め込まない
- 横スクロールを発生させない
- タップ領域と本文の可読性を優先する
- Headerはロゴ＋ハンバーガーメニュー
- Heroは縦構成を基本とする
- 固定CTAは小型・横書き
- セクション余白は80〜96px程度

### Tablet（768〜1023px）

- 一部を2列化する
- PCナビには切り替えず、HeaderはSP系を維持する
- アイコン等は必要に応じて2列にする
- Heroの2列化は実際の見え方を確認して判断する
- PCレイアウトを無理に縮小しない

### PC（1024px〜）

- PCナビへ切り替える
- Header内にCTAを配置しない
- 画面右端に縦型固定CTAを配置する
- 写真＋文章の左右配置を基本とする
- 必要に応じて2〜4列にする
- 写真サイズに強弱をつける
- 整った構成に、ごく軽い非対称性を加える
- 大きく崩したレイアウトにはしない
- カードを大量に並べない
- セクション余白は120〜160px程度

## Header・固定CTA

### PC Header（1024px〜）

- SENロゴとABOUT / LESSON / STUDIO / TRAINER / PRICE / FAQだけを配置する
- Header内にCTAを入れない
- ナビゲーションとして簡潔に保ち、余白感を優先する

### PC固定CTA

- 画面右端へ縦型で固定する
- 文言：**初回体験を予約する**
- Deep Sage背景
- 白文字
- 細めの表現
- 強い影なし
- 広告バナーのように派手にしない
- SENの静かな世界観を維持する

### SP / Tablet Header（〜1023px）

- SENロゴ＋ハンバーガーメニュー
- メニュー内に正式ナビゲーションと「初回体験を予約する」を配置する

### SP / Tablet固定CTA

- 画面右下などに小型・横書きで固定する
- 文言：**初回体験を予約する**
- ユーザー操作やコンテンツ閲覧を邪魔しない位置・サイズにする

## レスポンシブ方針

- モバイルファースト
- 基準：375px
- 確認幅：375 / 390 / 768 / 1024 / 1366 / 1440
- SP：〜767px
- Tablet：768〜1023px
- PC：1024px〜
- 大きなレイアウト切り替えは`768px`と`1024px`の2段階を基本とする
- 必要性が明確でない限り、ブレークポイントを増やさない
- 確認幅6種類とmedia queryの数を混同しない
- 画像の固定高さを多用せず、`aspect-ratio`と`object-fit`を適切に使う

基本media query：

```css
@media (min-width: 768px) {
}

@media (min-width: 1024px) {
}
```

## 1366px / 1440pxの扱い

1366px・1440pxでは、基本的に新しいレイアウトへ切り替えない。PCレイアウトがワイド画面でも崩れないことを確認する。

- コンテンツが横に広がりすぎない
- 見出し・本文の行長
- Headerの間延び
- 写真サイズ
- 固定CTA
- セクション余白
- 横スクロール
- コンテナ位置

## コンテナ幅の方向性

| 画面 | 目安 |
|---|---|
| SP | 左右余白 約24px |
| 768px | 左右余白 約32px |
| PC | `max-width: 1120〜1200px`程度 |

- 1440pxでも本文・コンテンツを無制限に広げない
- 数値は実装レビュー前の目安であり、固定の絶対値として扱わない
- 目安の範囲内で実際の画面を見て最終調整する

## 写真使用ルール

### 最重要方針

**人物写真を多用しない。**

```text
余白
↓
タイポグラフィ
↓
図解・アイコン
↓
少数の写真
```

### 写真シリーズ共通

- 少し明るめ
- 柔らかい自然光
- 日中
- フラット寄り
- 白飛びなし
- 暗すぎない
- 暖色すぎない
- 低〜中彩度
- 同じ撮影日に見える統一感
- 水平・垂直を重視
- 余白多め
- 極端な寄り・引きを避ける
- 派手なアングルを避ける
- 強い逆光・強い影を避ける

### 人物表現

- 過剰な笑顔や広告モデルのポーズを避ける
- カメラ目線を多用しない
- 会話中・集中中など自然な瞬間を優先する
- 過度な美肌加工を行わない
- 腹筋、ヒップ、痩身を強調しない
- 体型を商品化する表現を避ける

正式写真5点は再加工せず、台帳に記載した実在ファイルを使用する。

## アイコン・イラスト

正式採用済みアイコンの方向性：

- やわらかい女性向け線画
- 少しポップ
- 大人っぽい
- 子どもっぽくしない
- Deep Charcoal中心
- Sage / Pale Sageを補助使用
- 3Dなし
- グラデーションなし
- 強い影なし
- 医療アイコンのようにしすぎない

お悩みアイコンと特徴アイコンは、既存の正式PNGをそのまま使用する。新規作成や色変更は行わない。

## 姿勢チェック図解

- 正面・側面の人物と身体の軸を用いる
- 頭・肩・骨盤・全体バランスを分かりやすく示す
- 医学的な診断図にしない
- 「SENではどのような観点から身体を見るか」を説明する
- 正式PNGを再加工せず使用する

## ロゴ

- 正式採用済みの2段ワードマークを使用する
- タイポグラフィを主役にする
- 不要なシンボルを追加しない
- 色変更、変形、トリミング、影、グラデーションを加えない

## 避ける表現

- ストイック、派手、スポーツジム風
- 強い美容訴求、ダイエット広告風
- かわいすぎる装飾
- 医療機関のような無機質さ
- 強い影、過度な立体表現
- カードの過剰使用
- 不要な写真や人物の追加
- 過度なアニメーション

## 実装前に要確認

- Webフォントの具体的な読み込み方法とフォールバック
- PCコンテナ最大幅の最終値（1120〜1200pxの範囲で調整）
- 詳細なタイポグラフィスケール
- セクションごとの最終余白
- Focus表示と各配色のコントラスト
- 写真の表示比率と切り抜き位置
- 固定CTAの最終寸法とコンテンツに干渉しない配置
